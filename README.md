# Paddock Panda releases

This repository hosts the release downloads for **Paddock Panda**, a desktop app of track side calculators and a schedule assistant for macOS and Windows.

It contains no source code. Each release holds the installers for that version, along with the files the app uses to check for and download updates.

## Download

Go to the [Releases](../../releases/latest) page and pick the file for your computer:

| Platform | File |
| --- | --- |
| Windows | `Paddock-Panda-Setup-<version>.exe` |
| macOS (Apple silicon) | `Paddock-Panda-<version>-arm64.dmg` |
| macOS (Intel) | `Paddock-Panda-<version>-x64.dmg` |

The `.zip`, `.yml` and `.blockmap` files are used by the app's updater. You do not need to download them.

## Updates

Once installed, Paddock Panda checks this repository for new versions and lets you know when one is available.
